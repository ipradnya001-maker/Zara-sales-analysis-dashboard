# Zara Sales Analysis Dashboard

## Overview
This project presents an interactive Excel dashboard designed to analyze Zara sales data. The dashboard helps visualize key business metrics, identify sales trends, and compare performance across product categories and store locations.

## Objectives
- Analyze overall sales performance.
- Identify top-performing product categories.
- Compare sales across different store locations.
- Track customer purchasing patterns.
- Create an easy-to-use and interactive dashboard.

## Dataset
The dataset includes sales transaction records with the following attributes:

- Order ID
- Customer Name
- Product Category
- Product Name
- Quantity Sold
- Unit Price
- Total Sales
- Purchase Date
- Payment Method
- Store Location

## Dashboard Features
- KPI Cards for Total Sales, Orders, and Revenue
- Category-wise Sales Analysis
- Location-wise Performance Tracking
- Interactive Filters and Slicers
- Pivot Tables and Pivot Charts
- Dynamic Visualizations

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Key Insights
- Identifies the highest revenue-generating categories.
- Highlights top-performing store locations.
- Tracks sales trends over time.
- Supports data-driven business decisions.
